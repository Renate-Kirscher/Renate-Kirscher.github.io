Datenschutz

Dies ist ein privates, nicht-kommerzielles Reise- und Kochtagebuch. Verantwortlich: Renate Kirscher, renate.kirscher@googlemail.com.

Hosting

Die Seiten liegen bei GitHub Pages (GitHub Inc., USA). Beim Aufruf verarbeitet GitHub technisch notwendige Verbindungsdaten wie die IP-Adresse, um die Seite auszuliefern.

Besucherstatistik

Zur anonymen Besucherstatistik wird Cloudflare Web Analytics (Cloudflare Inc., USA) eingesetzt. Es werden keine Cookies gesetzt, keine Nutzerprofile erstellt und keine Besucher wiedererkannt. Erfasst werden nur zusammengefasste Angaben wie aufgerufene Seite, Herkunftsland, verweisende Seite und Browsertyp.

Kommentare

Wer einen Kommentar schreibt, übermittelt den angegebenen Namen und den Text; beides wird nach Freigabe öffentlich angezeigt. Eine E-Mail-Adresse wird nicht abgefragt. Zum Schutz vor Missbrauch wird die IP-Adresse höchstens 60 Sekunden lang gespeichert und danach automatisch gelöscht. Die Kommentare werden bei Cloudflare gespeichert. Auf Wunsch wird ein Kommentar jederzeit entfernt – eine kurze E-Mail genügt.

Schriften

Die Schriftarten werden von Google Fonts (Google LLC, USA) geladen; dabei wird die IP-Adresse an Google übermittelt.
